# rp-engine 开发日志 — 2026-04-12

## 概要

Phase 2: Skill System 实现。skill_set 节点类型 + generate 节点 skill_sets 集成 + load_skill/load_skill_reference 内置 tool。

---

## 1. 设计研究

调研了多个 skill/harness 架构参考：
- **Anthropic Skills** — Claude Code 的 .md 文件渐进加载模型
- **Claude Code** — CLAUDE.md harness + tool-based skill loading
- **Hermes agent** — 三级渐进式上下文注入（metadata → full → references）
- **Harness engineering** — 业界共识：LLM 驱动的记忆写回需更多实践

### 关键架构决策

| 决策 | 选择 | 原因 |
|------|------|------|
| Skill 存储 | 图节点（`skill_set`） | IDE 可见、可拖拽、可组合；不是隐式 workflow 级数据 |
| 加载机制 | Tool calling（`load_skill`） | rp-engine 作为 library 在容器中运行，无本地文件系统；tool calling 已有完整链路 |
| 引用方式 | Generate 显式 `skill_sets` 字段 | 明确数据流，避免隐式继承 |
| 命名冲突 | 构建时检查 | 用户 tools 不能叫 load_skill/load_skill_reference |
| Memory writeback | 推迟 | LLM 驱动的记忆更新，业界共识尚未成熟 |
| 规则触发 | 推迟 | LLM 自触发已足够，trigger_keywords 增加复杂度 |

| `src/nodes/skill_set.rs` | **新文件**。`SkillSetExecutor`：解析 skills 配置，content_file → content 解析，写入 state（`skills` 数组 + `_skill_count`） |
| `src/nodes/mod.rs` | 注册 `skill_set` executor |
| `src/nodes/generate.rs` | skill index 构建（从 state 读取 skill_sets 引用的节点输出）；metadata section 构建注入 system_prompt；`dispatch_tool_call` 提取：built-in tool 直接处理，user tool 走子图；`load_skill` 返回 skill content；`load_skill_reference` 验证 path 在 references 中后返回文件内容 |
| `examples/test_skill_set.rs` | **新文件**。端到端测试：skill_set 节点 → generate 节点，验证 LLM 使用渐进加载 |

### 核心实现要点

1. **SkillDef** — 统一 content 和 content_file 两种来源，执行时 resolve
2. **SkillSetExecutor** — 简单：解析 config → resolve content_file → 写 state
3. **Skill index building** — generate 节点从 state 读取所有 skill_sets 引用的节点输出，合并成统一 skill 索引
4. **Metadata injection** — 构建 `## Available Skills\n- name: description\n...` 注入 system_prompt 中间层
5. **dispatch_tool_call 提取** — 从 tool calling loop 中提取 tool dispatch 逻辑，区分 built-in tool（load_skill/load_skill_reference）和 user tool（子图执行）
6. **load_skill** — 在 skill index 中查找 name，返回 content 作为 tool result
7. **load_skill_reference** — 验证 (skill_name, path) 组合合法，读取文件返回
