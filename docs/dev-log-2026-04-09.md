## 2. Harness Instructions 实现

### 设计

Generate 节点内部 prompt render 阶段可扩展化。Harness 是第一层：workflow 级别的固定指令，注入到所有 generate 节点的 system_prompt 最前面。

**设计决策**：不拆 generate 为两个节点（tool calling loop 需要闭环），而是内部 pipeline 可扩展。

### 实现

**Commit:** `2706b69` on `upgrade` branch

| 文件 | 改动 |
|------|------|
| `src/schema/workflow.rs` | 新增 `HarnessConfig { instructions, files, memory_file }` + `PreparedWorkflow.harness` 字段 |
| `src/schema/mod.rs` | 导出 `HarnessConfig` |
| `src/engine/executor.rs` | `ExecutionConfig` 新增 `harness_instructions` + `harness_memory_file`；`execute_workflow` 在启动时解析 harness（内联文本 + 外部文件 + 记忆文件） |
| `src/nodes/generate.rs` | 新增 `compose_system_prompt(harness, skills, template)` 函数；system_prompt 构建改为分层组合 |
| `src/nodes/workflow_node.rs` | 子 workflow 继承 harness 配置 |

### YAML 格式

```yaml
harness:
  instructions: |
    你是专业数据分析助手。始终用中文回复。
  files:
    - "rules/output_format.md"
  memory_file: "harness_memory.json"
```

### System Prompt 组合顺序

```
harness instructions    ← 最高优先级
---
skill metadata          ← Phase 2 预留
---
template system_prompt  ← 模板自带的
```

### 验证

```
DEEPSEEK_API_KEY=... cargo run --example test_harness

✅ With Harness: system_prompt 包含 "你是一个专业的翻译助手" + 规则
✅ Without Harness: system_prompt 只有模板的 "You are a translator."
```
